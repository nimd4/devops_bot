# Ansible

## Описание

Данная ветка содержит сценарий автоматического развертывания инфраструктуры Telegram-бота с использованием **Ansible**.

После выполнения playbook автоматически выполняется:

- установка PostgreSQL;
- настройка репликации базы данных;
- клонирование проекта Telegram-бота с GitHub;
- установка Python и всех необходимых зависимостей;
- создание виртуального окружения;
- создание файла конфигурации `.env`;
- запуск Telegram-бота как системного сервиса (`systemd`).

# Инфраструктура

В проекте используются три виртуальные машины.

| Виртуальная машина | IP-адрес | Назначение |
|-------------------|-------------|--------------------|
| VM1 | 192.168.1.15 | PostgreSQL Master |
| VM2 | 192.168.1.16 | PostgreSQL Replica |
| VM3 | 192.168.1.18 | Telegram Bot |

---

# Требования

Перед запуском необходимо установить:

- Ansible
- SSH-доступ ко всем виртуальным машинам
- Настроенную авторизацию по SSH-ключам
- Git

Проверить подключение можно командой:

```bash
ansible all -i inventory -m ping
```

Ожидаемый результат:

```
vm1 | SUCCESS
vm2 | SUCCESS
vm3 | SUCCESS
```

---

# Запуск

Основной сценарий запуска:

```bash
ansible-playbook -i inventory playbook_tg_bot.yml
```

---

# Что выполняет playbook

## VM1

- установка PostgreSQL;
- создание базы данных;
- создание пользователя базы данных;
- создание пользователя репликации;
- настройка PostgreSQL;
- запуск сервиса PostgreSQL.

## VM2

- установка PostgreSQL;
- настройка репликации;
- подключение к Master;
- запуск реплики.

## VM3

- установка Python;
- установка Git;
- клонирование проекта Telegram-бота;
- создание виртуального окружения;
- установка зависимостей;
- создание файла `.env`;
- запуск Telegram-бота через `systemd`.
