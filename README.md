# DevOps Telegram Bot

## О проекте

Проект представляет собой Telegram-бота на Python, использующего базу данных PostgreSQL.

В репозитории реализованы два различных способа развертывания приложения:

- **Docker** — контейнеризация приложения;
- **Ansible** — автоматическое развертывание инфраструктуры на трех виртуальных машинах.

---

# Структура репозитория

Репозиторий разделен на две основные ветки.

## Ветка docker

Ветка предназначена для развертывания приложения при помощи **Docker** и **Docker Compose**.

Реализовано:

- сборка Docker-образов;
- запуск PostgreSQL;
- запуск Telegram-бота;
- использование Docker Compose;
- настройка через файл `.env`.

Основные файлы:

```
bot/
db/
docker-compose.yml
.env
README.md
```

---

## Ветка ansible

Ветка предназначена для автоматического развертывания инфраструктуры при помощи **Ansible**.

Реализовано:

- установка PostgreSQL;
- настройка Master–Replica репликации;
- клонирование проекта Telegram-бота с GitHub;
- установка Python и зависимостей;
- создание виртуального окружения;
- создание конфигурационного файла `.env`;
- запуск Telegram-бота как сервиса `systemd`.

Используются три виртуальные машины.

| ВМ | Назначение |
|----|------------|
| VM1 | PostgreSQL Master |
| VM2 | PostgreSQL Replica |
| VM3 | Telegram Bot |

Основные файлы:

```
ansible/
├── config-postgresql/
├── inventory
├── pgbass
├── playbook_tg_bot.yml
└── README.md
```
